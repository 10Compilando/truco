# 🃏 Truco

### Uma mistura de truco paulista, inteligência artificial e programação!

Projeto desenvolvido para o **Blend de IA**, unindo desenvolvimento de software, inteligência artificial e criatividade em uma versão jogável do tradicional Truco Paulista.

O jogo coloca o jogador frente a frente com o Seu Nivaldo, um adversário virtual com decisões próprias e expressões que acompanham os acontecimentos da partida.

> ☕ Um projeto do Blend de IA: ideias, código e inteligência artificial na mesma mesa!

---

## 🎮 Sobre o projeto

O **Truco do Seu Nivaldo** é um jogo desenvolvido em PHP que busca reproduzir a experiência do Truco Paulista, incluindo as regras de disputa das vazas, o sistema de apostas e as decisões do adversário controlado pelo computador.

Mais do que distribuir cartas, o desafio é implementar a lógica do jogo, controlar o estado da partida e criar uma experiência interativa.

## ✨ Funcionalidades

### 🃏 Truco Paulista
- Baralho de 40 cartas.
- Distribuição de três cartas por jogador.
- Carta vira para determinar as manilhas.
- Hierarquia de cartas e disputa de vazas.
- Mãos disputadas em até três vazas.
- Histórico das cartas jogadas.

### 🔥 Sistema de truco
- Pedidos de Truco, Seis, Nove e Doze.
- Possibilidade de aceitar, aumentar a aposta ou correr.
- Pontuação conforme o valor da disputa.
- Controle do fluxo de apostas durante a mão.

### 🧠 Adversário com inteligência artificial
- Decisões automatizadas durante a partida.
- Avaliação das cartas e da situação do jogo.
- Escolhas relacionadas às apostas e à continuidade da disputa.
- Respostas de acordo com os acontecimentos da partida.

### 😎 Expressões do Seu Nivaldo
O adversário possui diferentes expressões visuais para dar personalidade à experiência:

- 😌 Esperando a jogada.
- 🤔 Pensando e analisando as cartas.
- 😏 Em postura desafiadora.
- 💪 Pedindo truco.
- 🎉 Comemorando suas vitórias.
- 😠 Reagindo às vitórias do jogador.

### 🏆 Sistema de partidas
- Partidas com objetivo de 12 pontos.
- Placar acumulado.
- Série disputada em múltiplas partidas.
- Identificação do encerramento das mãos e partidas.

### 🖥️ Interface
- Mesa virtual com cartas dos jogadores.
- Organização visual das vazas.
- Identificação das cartas jogadas.
- Recursos visuais e mensagens de estado da partida.
- Interface adaptável a diferentes telas.

## 💻 Tecnologias utilizadas

- **PHP** — lógica e processamento do jogo.
- **HTML** — estrutura da interface.
- **CSS** — apresentação visual.
- **JavaScript** — recursos interativos, conforme implementados no projeto.
- **Sessões PHP** — manutenção do estado da partida.

A implementação organiza a lógica do jogo e a interface em componentes de código, com o objetivo de manter as regras e a experiência de jogo integradas.

## 🚀 Como executar

O projeto precisa de um ambiente com suporte a PHP.

1. Clone ou baixe este repositório.
2. Coloque os arquivos em um ambiente com PHP instalado ou em uma hospedagem compatível.
3. Preserve a estrutura de pastas, especialmente os arquivos e as imagens dentro de `img/`.
4. Acesse o arquivo principal pelo servidor PHP ou pelo navegador, usando a URL do ambiente configurado.

Para testar localmente, se o PHP estiver instalado, entre na pasta do projeto e execute:

```bash
php -S localhost:8000
```

Depois, acesse:

`http://localhost:8000`

**Observação:** o GitHub armazena o código-fonte, mas não executa diretamente a aplicação PHP. Para disponibilizar o jogo na internet, é necessário um servidor compatível com PHP.
